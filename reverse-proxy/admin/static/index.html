01 / CREDENTIALS

添加登录凭据

优先使用“添加账号 → 浏览器登录”，在官方页面授权后自动保存，无需桌面客户端。也可在桌面端登录后，按 Win + R 打开以下目录导入文件：

%LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth

将其中的 .info 文件拖入“添加账号”，或粘贴其 JSON 内容。支持保留多个账号并手动切换；浏览器授权和文件导入可同时使用。
